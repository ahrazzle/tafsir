# Tafsir

Tafsir study — Quranic exegesis with structured navigation by juz/surah, morphology, and content layers.

This is the production site. See `tafsir-staging` for the staging build reviewed before promotion.

## Structure
- `index.html` / `app.js` — frontend
- `data/` — surah and tajweed datasets
- `etl-tafsir.py` / `arabic_normalize.py` — ETL and normalization
- `ARCHITECTURE.md` / `ETL-design-tafsir.md` — design docs
